## 🎓 What I'm Learning: Week by Week

### Week 1 – Developer Tools & Environment Setup

Getting comfortable with the tools developers use every day.

- Introduction to developer tools.
- Browser DevTools and Chrome Inspector.
- Visual Studio Code setup.
- Git and GitHub fundamentals.
- Understanding web browsers and how they work.
- Working with the development environment.

### Week 2 – HTML Fundamentals

My introduction to building the structure of web pages.

- HTML document structure.
- Semantic HTML elements.
- Headings, paragraphs and links.
- Images and media.
- HTML forms and elements.
- Building a personal profile page.
- Writing clean and structured markup.

### Week 3 – CSS Basics & Box Model

Learning how to turn basic HTML structures into properly styled web pages.

- Introduction to CSS.
- CSS selectors and properties.
- Connecting CSS to HTML.
- Styling HTML elements.
- The CSS Box Model.
- Content, padding, borders and margins.
- Width, height and element sizing.
- Spacing and layout.
- Using browser DevTools to inspect CSS.

### Week 4 – Stats Preview Card Component

My first practical component-building assignment using a design reference.

- Understanding design mockups.
- Translating designs into HTML and CSS.
- CSS Flexbox.
- Responsive layouts.
- Media queries.
- Image positioning.
- Typography and colour matching.
- Desktop and mobile layouts.
- Browser debugging.

### Week 5 – Clipboard Landing Page

Building a complete multi-section landing page.

- Structuring multi-section web pages.
- Custom fonts and typography.
- CSS Flexbox.
- Responsive design.
- Mobile-first considerations.
- Buttons and hover states.
- Footer layouts and social links.
- Image and SVG asset management.
- Cross-browser testing.
- Git and GitHub workflow.

### Week 6 – JavaScript Fundamentals

Moving from static pages to programming logic.

- Variables: `let` and `const`.
- JavaScript data types.
- Strings, numbers, booleans and null.
- Arithmetic operators.
- Assignment operators.
- Type conversion.
- `parseInt()`, `parseFloat()`, `Number()` and `String()`.
- Conditional statements.
- Comparison operators.
- Template literals.
- Console logging and debugging.
- Running JavaScript with Node.js.

### Week 7 – JavaScript Arrays & Objects

Going deeper into how JavaScript stores and works with data.

- Understanding arrays.
- Working with objects.
- Accessing and manipulating data.
- Understanding properties and values.
- Practising JavaScript data structures.
- Applying programming logic to practical exercises.

### Week 8 – Advice Generator Application

Building an interactive Advice Generator application using a Frontend Mentor challenge.

This was an opportunity to bring HTML, CSS and JavaScript together in a functional project.

What I worked on:

- Building a responsive interface from a design reference.
- Structuring the application with HTML.
- Styling the interface with CSS.
- Implementing JavaScript interactions.
- Working with the Advice Slip API.
- Fetching and displaying dynamic advice.
- Implementing the dice button to generate new advice.
- Adding hover interactions.
- Handling API responses.
- Testing the application in the browser.

### Week 9 – JavaScript Prerequisites for React & TypeScript

Preparing for React by strengthening my JavaScript foundation and getting introduced to TypeScript.

**JavaScript prerequisites:**

- Core JavaScript concepts needed for React.
- Understanding functions and modern JavaScript syntax.
- Working with arrays and objects.
- Understanding modern JavaScript features.
- Preparing to work with component-based development.

**Introduction to TypeScript:**

- Understanding what TypeScript is.
- Type annotations.
- Basic data types.
- Interfaces.
- Working with typed variables and objects.
- Understanding how types improve code readability and predictability.

### Week 10 – React Hooks

My introduction to managing component state, side effects and references in React.

I built four independent React components using Vite to understand three commonly used React Hooks.

**1. Counter – useState**

- Managing state with `useState`.
- Initialising state.
- Updating state through event handlers.
- Incrementing, decrementing and resetting values.
- Understanding how state updates trigger re-renders.

**2. Todo List – useState**

- Managing arrays in React state.
- Controlled input fields.
- Handling user input.
- Adding tasks to an array.
- Removing individual tasks.
- Using array methods such as `map()` and `filter()`.

**3. Profile Card – useEffect**

- Understanding side effects.
- Running effects when a component mounts.
- Simulating asynchronous data loading.
- Using `setTimeout()`.
- Managing loading states.
- Cleaning up timers with `clearTimeout()`.

**4. Search Box – useRef**

- Creating references to DOM elements.
- Automatically focusing an input field.
- Managing mutable values with `useRef`.
- Tracking component renders.
- Understanding the difference between `useState` and `useRef`.

**Technologies:** React, Vite, JavaScript and ESLint.
